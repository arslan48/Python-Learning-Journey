# Python Learning Journey

A beginner-friendly collection of Python practice files, mini projects, and revision exercises. This repository documents my progress while learning Python step by step, and it can also help other beginners practice the same topics.

## What You Will Find Here

- Python basics: variables, data types, strings, conditions, lists, tuples, loops, functions, dictionaries, and sets
- File handling practice: reading, writing, appending, and managing text files
- Object-oriented programming: classes, inheritance, overriding, and small class-based examples
- NumPy practice: arrays, slicing, reshaping, filtering, broadcasting, aggregation, saving/loading data, and matrix operations
- Pandas basics: Series practice and simple filtering
- Revision projects: mixed exercises for logic building and confidence

## How To Use This Repository

1. Pick a topic folder.
2. Open a small `.py` file.
3. Read the code and guess the output.
4. Run the file.
5. Modify the code and try again.
6. Build your own version of the same idea.

## Running A File

Use Python from the terminal:

```bash
python path/to/file.py
```

Example:

```bash
python 01_python_fundamentals/04_loops/for_loop.py
```

On Windows, if `python` does not work, try:

```bash
py path/to/file.py
```
