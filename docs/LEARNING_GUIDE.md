# Learning Guide

This repository is organized as a step-by-step Python learning path.

## Suggested Order

1. Start with `01_python_fundamentals/01_variables_and_datatypes`.
2. Continue through strings, lists, loops, functions, dictionaries, and sets.
3. Practice reading and writing files in `02_file_handling`.
4. Learn classes and inheritance in `03_object_oriented_programming`.
5. Move into NumPy in `04_numpy`.
6. Try Pandas basics in `05_pandas`.
7. Revisit mixed practice in `06_revision_projects`.

## How To Practice

- Open one file at a time.
- Read the code first.
- Predict the output before running it.
- Change the input values and run it again.
- Rewrite the same idea without looking at the original file.

## Notes For Contributors

This is a beginner learning repository, so simple examples are welcome. If you add code, keep file names clear and place them in the matching topic folder.
