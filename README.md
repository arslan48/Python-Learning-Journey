# Python Learning Journey

A structured collection of Python scripts, exercises, and mini-projects tracking my progress from basics to advanced.

## 📚 What You Will Find Here

- **Python Basics**: variables, data types, strings, conditions, lists, tuples, loops, functions, dictionaries, and sets
- **File Handling**: reading, writing, appending, and managing text files
- **Object-Oriented Programming**: classes, inheritance, overriding, and practical OOP examples
- **NumPy**: arrays, slicing, reshaping, filtering, broadcasting, aggregation, and matrix operations
- **Pandas**: Series, DataFrames, and data manipulation techniques
- **Matplotlib**: data visualization, plotting, and creating charts
- **Revision Projects**: comprehensive exercises to reinforce learning and build confidence

## 🚀 How To Use This Repository

1. Pick a topic folder that matches your current learning level
2. Open a `.py` file and read through the code
3. Try to predict the output before running it
4. Run the file using Python
5. Modify the code and experiment with changes
6. Build your own version of the same concepts

## 📖 Recommended Learning Path

Follow this sequence for the best learning experience:

1. Variables and data types
2. Strings and conditional statements
3. Lists and tuples
4. Loops
5. Functions
6. Dictionaries and sets
7. File input/output
8. Object-oriented programming
9. NumPy
10. Pandas basics
11. Matplotlib and data visualization
12. Revision projects

## 💻 Running Files

### On Linux/macOS/Windows:

```bash

```

